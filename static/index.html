Running Your FlyBoard: Cloud Run Free Tier & Raspberry Pi

1. Why Google Cloud Run Works at ~$0.00/mo (Free Tier)

Cloud Run charges only while an HTTP request is actively being processed (when configured with default request-based billing and --min-instances=0).

  • Google Cloud Free Tier Allowance: Includes 2 million requests, 180,000 vCPU-seconds, and 360,000 GiB-seconds free every month.
  • How FlyBoard Uses It: Your browser or Raspberry Pi polls /api/flights every 5 seconds (~200ms execution time per poll). Even running 12 hours a day every day of the month, that is ~259,000 requests and ~51,000 vCPU-seconds—less than 30% of the monthly free tier!
  • Smart Idle Pause: When you close the browser tab or turn off the monitor at night, Cloud Run scales to zero instances within minutes and consumes zero compute.
gcloud run deploy kgrr-flyboard \
  --source . \
  --region us-central1 \
  --allow-unauthenticated \
  --min-instances 0 \
  --max-instances 2 \
  --memory 256Mi \
  --cpu 1

2. Raspberry Pi Kiosk + Monitor Setup

Once deployed to Cloud Run (or running locally on the Pi), point a Raspberry Pi connected to an ultra-wide bar LCD (like a 1920×480 stretched display) or standard monitor into fullscreen Chromium Kiosk mode: 

chromium-browser --kiosk --app=https://YOUR-CLOUD-RUN-URL.run.app \
  --start-fullscreen --noerrdialogs --disable-infobars
